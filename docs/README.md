## Reading order

1. Read the [R1 game specification](r1-game-specification.md) for the normative
   rules, information sets, chance laws, and terminal accounting.
2. Read the [original DCFR derivation request](dcfr/derivation-request.md) for
   the shared objective and constraints.
3. Compare the [peer designs](dcfr/README.md#peer-derivations) and
   [street chapters](dcfr/README.md#compare-by-street) in
   river → turn → flop → preflop order.
